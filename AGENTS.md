# Production operator instructions

- Follow [the browser resource policy](docs/browser-sessions.md): reuse one tab per needed service/account, save evidence, and close completed temporary tabs. Inspect current live state first; preserve active processing and unsaved work. Never claim cleanup when browser control is unavailable.
- Keep production catalogs, publication observations, commercial policy and media out of this public source checkout. Use the private portable tracker described in [the tracker guide](docs/delivery-tracker.md).
- Preserve a job's explicit implementation/profile snapshot. Adopt new source at an idle checkpoint and replan/revalidate affected jobs; a template or tracker update cannot approve old media or establish that a post is Public.
